# Local Assesium logo assets

The storage-proxy logo URL is unavailable in the local preview. The project contains two local public assets:

- `client/public/assesium-logo.png`: transparent logo with orange Assesium mark and white wordmark, suitable for dark backgrounds.
- `client/public/assesium-logo2.png`: logo with dark textured background, less suitable for the dashboard sidebar.

The dashboard light sidebar should use the local `assesium-logo.png` asset, with sizing/cropping adjusted so the website mark is visible without the broken remote path.
